Configuration des Logos (Custom Branding)

Jellyfin 12 remplace les assets de branding en statique (favicon, icon-transparent, banner-light, banner-dark).

Pour chaque champ : vous pouvez soit coller une URL, soit cliquer pour importer un fichier. L'aperçu sera affiché en direct.

Favicon et Apple Touch Icon

S'affiche dans l'onglet du navigateur, sur les écrans d'accueil mobiles, et dans le Manifeste PWA.
Cliquer pour importer une image
L'URL ne pointe pas vers une image valide ou est inaccessible.

Logo Transparent

Affiché en haut à gauche et dans le menu latéral.
Cliquer pour importer une image
L'URL ne pointe pas vers une image valide ou est inaccessible.

Bannière (Logo complet)

S'affiche sur l'écran de connexion et remplace le texte du menu en haut à gauche sur PC/Tablette.
Cliquer pour importer une image
L'URL ne pointe pas vers une image valide ou est inaccessible.

Paramètres du Manifeste (PWA)

Configurez l'apparence de Jellyfin lorsqu'elle est installée comme application web (PWA).
